## 🚀 Quick Start

1. **Option 1 (Direct in Browser):**  
   Double click [`index.html`](file:///c:/MCIOTLAB/index.html) to open the interactive lab portal directly in your browser.

2. **Option 2 (Local Web Server):**  
   Double click [`start_server.bat`](file:///c:/MCIOTLAB/start_server.bat) or run:
   ```powershell
   python -m http.server 8000
   ```
   Then open `http://localhost:8000` in your web browser.

## 📂 Included Resources

- **`lab_manual.pdf`**: Full official 87-page lab manual embedded directly inside the website viewer with page jumping controls and download buttons.
- **`index.html`**: Master web application with search, filtering, code viewer, circuit diagrams, and simulation launchers.
- **`styles.css`**: Responsive, modern glassmorphic design system with full Light & Dark mode support.
- **`app.js`**: Interactive search filter, copy code utility, lightbox diagram viewer, and quick-links engine.
- **`images/`**: High-resolution circuit diagrams, pinout guides, and schematics extracted from the official manual.
